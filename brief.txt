- Repo name:         crypto-lab-accumulator
- Short name (H1):   Accumulator
- Subtitle:          RSA accumulator · dynamic membership · non-membership proofs
- One-liner:         Cryptographic accumulators where a constant-size digest commits to a dynamic set and supports both membership and non-membership proofs — certificate revocation without downloading a list.
- Concept to teach:  An accumulator is like a Merkle root that never grows, no matter how large the set gets. Adding or removing elements updates the digest but doesn't change its size. The killer feature over Merkle trees is non-membership proofs: prove that an element is NOT in the set, which is what certificate revocation actually needs.
- Primitives/spec:   Benaloh-de Mare 1993 (original accumulator), Baric-Pfitzmann 1997 (collision-free), Camenisch-Lysyanskaya 2002 (dynamic accumulator with non-membership), Li-Li-Xue 2007 (universal accumulator)
- Accent (--accent): #0ea5e9
- Favicon emoji:     🧮
- In scope:          RSA accumulator: accumulate a set of elements into a single group element; membership witness: prove element ∈ set with a constant-size proof; non-membership witness: prove element ∉ set; dynamic update: add/remove elements and watch the digest update while existing proofs remain verifiable (or require updating); comparison panel: accumulator vs Merkle tree (digest size constant vs O(log n), non-membership trivial vs expensive, update cost); revocation use case: add revoked certificates, prove a certificate is NOT revoked; real modular exponentiation (BigInt)
- Non-goals:         No pairing-based accumulators (mention as extension); no batched updates; no zero-knowledge accumulator proofs; RSA modulus is toy-sized for browser performance — state this honestly; links to Key Mirror and Credential Veil
